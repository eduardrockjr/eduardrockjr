# Telegram Media Downloader

Script em Python desenvolvido para automação de download de mídias (fotos, vídeos e documentos) de grupos e canais do Telegram.

## 🚀 Funcionalidades
* **Verificação de Duplicatas:** O script checa se o arquivo já foi baixado localmente antes de iniciar o download, evitando duplicatas e economizando banda.
* **Controle de Sessão:** Utiliza a biblioteca Telethon para interagir com a API do Telegram de forma segura.

## 🛠️ Tecnologias Utilizadas
* `Python`
* `Telethon` (Manipulação da API do Telegram)
